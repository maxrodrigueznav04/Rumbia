# Instrucciones para Claude Code en este repo

## Pull requests

Cuando termines un cambio y lo subas en un PR, fusiónalo tú mismo directo
(sin preguntar primero) en cuanto los checks pasen y no haya conflictos.
No hace falta esperar confirmación del usuario para cada PR.

La única excepción es un cambio genuinamente peligroso o de alto impacto
(por ejemplo: algo que pueda tumbar producción, borrar datos, tocar
facturación/Stripe de forma irreversible, o cualquier cosa donde el costo
de estar equivocado sea alto y difícil de revertir). En esos casos sí
detente y pregunta antes de fusionar.
