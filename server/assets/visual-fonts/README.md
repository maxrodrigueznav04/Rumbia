# Tipografías de las propuestas

Playfair Display, Libre Baskerville y Work Sans, pesos 400 y 700, subconjunto latino.
Copias de los mismos paquetes Fontsource del cliente (ver su package-lock.json),
con las licencias OFL conservadas en esta carpeta. Se incrustan en el HTML/PDF
para que la tipografía no dependa de las fuentes instaladas en Windows o Linux.
Si se actualizan los paquetes del cliente, actualizar también estas copias.
