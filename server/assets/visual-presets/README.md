# Arte incluido en las plantillas visuales

Estos seis JPEG se generaron con la herramienta integrada de generación de imágenes de Codex el 25 de septiembre de 2026 y se codificaron a JPEG para cargar rápido y caber en el PDF. No proceden de un banco de imágenes. Son imágenes conceptuales: no representan el destino real de una propuesta. La agencia puede sustituir el arte de portada por una imagen propia o con licencia; esa subida conserva la confirmación de derechos ya implementada.
